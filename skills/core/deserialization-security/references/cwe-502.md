# CWE-502: Deserialization of Untrusted Data

Source: <https://cwe.mitre.org/data/definitions/502.html>. Checked: 2026-07-28.

CWE-502 applies when data supplied from an insufficiently trusted source is deserialized with a
format/runtime that can create objects or trigger behavior beyond plain data parsing. Prefer a
data-only format, strict schema, and a maintained parser. Where migration is impossible, constrain
types and resources and isolate the legacy consumer; do not rely on encoding or secrecy.
