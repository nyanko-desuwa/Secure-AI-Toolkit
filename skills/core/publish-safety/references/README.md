Two things to know before quoting any of it.

ASVS is cited at chapter level only. 5.0.0 renumbered heavily from 4.0.3, so a requirement ID
recalled from memory is a guess that looks verifiable. Chapter citations are honest and still
useful.

Platform behaviour changes faster than a standard does. Push protection defaults, tier
requirements, and packaging precedence are the kind of detail that moves in a quarter.
[platform-controls.md](platform-controls.md) records what the vendor documentation said on
2026-07-28 and names the claims it could not confirm rather than filling them in.
