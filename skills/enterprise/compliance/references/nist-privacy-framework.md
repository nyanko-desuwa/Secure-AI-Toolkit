# NIST Privacy Framework

Checked: 2026-07-28

Primary source fetched: <https://www.nist.gov/privacy-framework/privacy-framework>

The page identifies the published framework as Version 1.0 (January 2020), titled "The NIST
Privacy Framework: A Tool for Improving Privacy through Enterprise Risk Management." The site
also lists Version 1.1 as a new project/working effort; this skill does not treat that as a final
published edition.

## How to use it for technical evidence

Use the framework as a risk-management vocabulary, not as a certification checklist. Start with
the concrete control and evidence:

- generated data inventory -> identify processing and privacy risk;
- purpose, basis, and retention metadata -> govern processing choices;
- access, deletion, and portability paths -> control data lifecycle requests;
- masking, encryption, and minimised telemetry -> protect data processing;
- audit events and CI evidence -> communicate and demonstrate outcomes.

The page content fetched in this environment linked the Core downloads but did not enumerate the
five Core Function names. No function ID or category ID is therefore cited here.

## Deliberate omissions

The NIST Privacy Framework Core Function names and subcategory identifiers are unverified in this
reference. Fetch the Core PDF/XLSX from NIST before citing a function or subcategory in an external
mapping. NIST alignment does not establish GDPR, HIPAA, PCI DSS, or any other legal status.
